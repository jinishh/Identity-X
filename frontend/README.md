# Case-File Vault — web app

React 19 + Vite + TypeScript + Tailwind v4. See the [root README](../README.md) for how to run.

- `npm run dev` — dev server on :5173, proxies `/api` to the API on :8010
- `npm run gen:api` — regenerate `src/api/schema.d.ts` from `../contracts/openapi.yaml`
- `npm run build` — type-check and production build
